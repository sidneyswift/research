**How does it work?**

Sparkle is inspired by Tiago Forte’s PARA methodology — the idea that files should be sorted by actionability. I took PARA and thought to myself: how do I make it simple and automatic? The result is Sparkle.

Sparkle sorts your files into two folders: Recents and Archives.

**Recents **is any file that has been created or modified in the last 3 days
