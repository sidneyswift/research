# Artifacts

The runnable things being studied. Four sub-types, each with its own schema and index:

- [skills/](skills/_index.md) — individual skills (Anthropic official + Claude.ai Skills + community/cross-platform skills)
- [plugins/](plugins/_index.md) — plugins (collections of skills + commands + agents + hooks + MCP servers)
- [mcp-servers/](mcp-servers/_index.md) — MCP servers (the integration layer)
- [projects/](projects/_index.md) — frontier projects/systems/products that aren't a single skill, plugin, or MCP server

For *ideas* rather than runnable things, see [../concepts/](../concepts/_index.md). Schemas live in [../\_schemas/](../_schemas/). Use them.
