# Original notes on API documentation knowledge

Read: arXiv:1907.13260v1, Alex Cummaudo, Rajesh Vasa, John Grundy (2019-07-30). Retrieved 2026-11-05. Full six-page PDF read, especially methods, Table III, threats, future work. Original paraphrase, not a paper snapshot.

The mapping study selects 21 primary studies and organizes 34 recommendations under usage description, design rationale, domain concepts, support artifacts and documentation presentation. Table III counts how many included studies recommend each category: snippets 15/21, tutorials 12/21, low-level reference 11/21. These are frequencies within a selected literature sample, not measured productivity gains or the percentage of developers who prefer a feature. The taxonomy gives coverage beyond reference, including limitations, terminology, dependencies, errors, architecture and navigation.

Limitations: preliminary mapping; primary selection and categorization initially performed by first author; test-retest used, independent inter-rater work and practitioner validation proposed as future work; database/query/English/full-text selection limits. Even duplicate totals differ in prose (549 versus 514), so do not repeat an exact deduplication count. No universal thirty-line example limit follows from a taxonomy category.
